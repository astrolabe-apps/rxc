# @rx-controls/forms-json

The Forms v2 JSON loader: ControlDefinition and SchemaField in, the same JSX a hand-written form would be out, plus a list of everything it could not carry across. The only package that reads a ControlDefinition, and the only one that depends on jsonata.

Part of Forms v2, an alpha: `npm install @rx-controls/forms-json@alpha`. The eight Forms v2
packages are released together at one version — upgrade them together.

**Upgrading?** Each release's [changelog](https://github.com/astrolabe-apps/rxc/blob/main/docs/FORMS-V2-CHANGELOG.md)
lists what you change first.
