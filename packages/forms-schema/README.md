# @rx-controls/forms-schema

The canonical ControlDefinition and SchemaField JSON types, builders and self-describing schemas — the format the C# server (Astrolabe.Schemas) emits, byte for byte. No React.

Part of Forms v2, an alpha: `npm install @rx-controls/forms-schema@alpha`. The eight Forms v2
packages are released together at one version — upgrade them together.

**Upgrading?** Each release's [changelog](https://github.com/astrolabe-apps/rxc/blob/main/docs/FORMS-V2-CHANGELOG.md)
lists what you change first.
