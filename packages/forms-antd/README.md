# @rx-controls/forms-antd

The Forms v2 Ant Design implementation: every registry slot drawn with antd, whose chrome is runtime theme tokens rather than classes.

Part of Forms v2, an alpha: `npm install @rx-controls/forms-antd@alpha`. The eight Forms v2
packages are released together at one version — upgrade them together.

**Upgrading?** Each release's [changelog](https://github.com/astrolabe-apps/rxc/blob/main/docs/FORMS-V2-CHANGELOG.md)
lists what you change first.
