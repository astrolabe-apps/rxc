# @rx-controls/forms-react

The Forms v2 contract: reactive props, presence and scope, the boundaries every field, collection, group, display and action is built from, the containers, and the registry an implementation fills. No DOM, no class strings.

Part of Forms v2, an alpha: `npm install @rx-controls/forms-react@alpha`. The eight Forms v2
packages are released together at one version — upgrade them together.

**Upgrading?** Each release's [changelog](https://github.com/astrolabe-apps/rxc/blob/main/docs/FORMS-V2-CHANGELOG.md)
lists what you change first.
