# @rx-controls/forms-mui

The Forms v2 MUI implementation: every registry slot drawn with @mui/material, and the contract's regression gate.

Part of Forms v2, an alpha: `npm install @rx-controls/forms-mui@alpha`. The eight Forms v2
packages are released together at one version — upgrade them together.

**Upgrading?** Each release's [changelog](https://github.com/astrolabe-apps/rxc/blob/main/docs/FORMS-V2-CHANGELOG.md)
lists what you change first.
