# @rx-controls/forms-html

The Forms v2 HTML implementation: every registry slot drawn as plain DOM, every class it emits in one HtmlTheme, and nestable theme providers.

Part of Forms v2, an alpha: `npm install @rx-controls/forms-html@alpha`. The eight Forms v2
packages are released together at one version — upgrade them together.

**Upgrading?** Each release's [changelog](https://github.com/astrolabe-apps/rxc/blob/main/docs/FORMS-V2-CHANGELOG.md)
lists what you change first.
