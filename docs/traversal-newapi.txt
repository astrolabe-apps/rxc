I'm still trying to get the traversal APIs for ControlDefinition and SchemaField as good as possible. Let's start with some definitions.

* SchemaField (actual TS type)
    Represents a single json field - has a field name, type etc.
* SchemaTree (not a ts type)
    A schema tree of SchemaField's starting with a SchemaField[] array.
* SchemaTreeMap (not not a ts type)
    A map of schema names to SchemaTree's. A type of SchemaField which represents an object (CompoundField) 
    can reference another SchemaTree by name which uses the SchemaField[] as it's children.
 
 * ControlDefinition (actual TS type)
    Represents a single control definition, has an optional unique id, some have data binding references to SchemaFields.
 * ControlTree (not a ts type)
    A control tree of ControlDefinition's starting with a ControlDefinition[] array.
 * ControlTreeMap (not not a ts type)
    A map of control names to ControlTree's. Any ControlDefinition can have it's children resolved 
    either by a local unique id or a reference to another ControlTree by name and a local unique id within that tree.

This is all simple except for the fact that the SchemaTrees and ControlTrees can be backed by Controls in an editor scenario. 
E.g. Control<SchemaField[]> and Control<ControlDefinition[]>
So we need to support reactivity when traversing these trees.

I like the idea of the SchemaTree having an api like:

interface SchemaTree {
   getRoot(rd: ReadContext): SchemaCursor;
   getById(rd: ReadContext, id: string): SchemaCursor | undefined;
}

interface SchemaCursor {
   field: SchemaField;
   // these are the resolved children
   children: SchemaCursor[];
   parent?: SchemaCursor; 
}

However, this leaves the problem of SchemaCursor only being scoped to the ReadContext that started it and not suitable to store as a stable reference.
Maybe:

interface SchemaCursorRef  {
    id: string; 
    get(rd: ReadContext): SchemaCursor;
}

interface SchemaTree {
   root: SchemaCursorRef;
}

interface SchemaCursor {
   ref: SchemaCursorRef;
   field: SchemaField;
   // these are the resolved children
   children: SchemaCursor[];
   parent?: SchemaCursor; 
}
